# Contributing

Issues and pull requests are welcome.

- Report a bug or ask for a feature in the [issue tracker](https://github.com/ifonso/AAS-Workingbench/issues).
  For a bug, say what you did, what you expected, and what happened, and attach a package that shows it if you may share one.
- To change code, read the [development guide](docs/contributing/development.md) to set up and run the checks, then the [testing guide](docs/contributing/testing-guide.md), the [style guide](docs/contributing/style-guide.md), the [branching guide](docs/contributing/branching.md), and the [Conventional Commits guide](docs/contributing/conventional-commits.md).
- Describe changes that users will notice in [CHANGELOG.md](CHANGELOG.md).
